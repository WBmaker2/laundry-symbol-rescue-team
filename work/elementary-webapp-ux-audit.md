## Baseline learner observations

1. 320×800과 375×812에서 앱 shell과 첫 미션 CTA를 찾을 수 있었고, progress strip만 의도적으로 가로 이동했습니다.
2. 표시 확대 후 첫 기호의 오답 상태는 확인 버튼 초점을 유지했고, 새 문구는 현재 그림에서 다시 볼 모양과 다음 선택 행동을 말합니다.
3. 계획 제출·위험 예보의 빈 제출은 상태 영역으로 이유를 말하고 제출 버튼에 초점을 유지했습니다.
4. 단계 제목은 전환 뒤 focus/scroll 되어 새 화면의 시작점을 잃지 않습니다.
5. 모든 결과는 가상 재료 모형의 가능성으로만 말하며 실제 라벨·보호자·교사 확인을 우선합니다.

## Review notes

- `npm run check`는 구현 완료 후 다시 실행해 lint, typecheck, Vitest, build, Pages 자산 smoke를 모두 확인합니다.
- 로컬 macOS Chromium은 이전 권한 오류로 CLI E2E를 실행하지 않으며, CI Ubuntu 또는 권한이 정상인 Chromium을 별도 게이트로 둡니다.
- 실제 초등학생·교사·Safari 수동 승인은 자동 테스트 결과와 구분해 기록해야 합니다. 이 문서는 사용성 개선 근거이지 실제 학생 승인 결과가 아닙니다.
