- 실행일: 2026-08-31
- 전체 후보 문자열은 `work/elementary-webapp-ux-language-candidates.md`에 보존했습니다.
- 후보 장부는 자동 문장 후보 수집일 뿐 학년 적합성 인증이나 자동 치환 결과가 아닙니다.

## Preserved domain terms

- `표백`, `회전식 건조`, `다림질`, `전문 관리`, `상대 자원 사용`, `가상 재료 모형`은 판정 모델과 factual 설명에 연결된 용어라서 임의의 쉬운 말로 바꾸지 않습니다.
- 실제 제품 라벨과 보호자·교사 확인 우선 문장은 유지합니다.
- 정답 선택지를 오답 피드백에 직접 노출하지 않고, 숫자·선·점·모양 관찰 단서만 제공합니다.

## Copy acceptance checklist

- [x] 문장마다 학습자가 다시 볼 대상과 다음 행동이 있습니다.
- [x] 오답 문장에 비난·확정적 실제 손상 표현이 없습니다.
- [x] `careSymbolIds` 8개 모두 비어 있지 않은 단서를 가집니다.
- [x] 320px·375px에서 안내 문장이 내부 ID 없이 줄바꿈됩니다.
- [ ] 실제 초등학생·교사 수업에서의 이해도 확인은 별도 수동 게이트입니다.
