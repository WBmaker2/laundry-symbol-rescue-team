# Elementary Web App Simulation Decision

## Decision

`not-needed` — 이번 개선에서는 새 게임 엔진·2D/3D 시뮬레이션을 추가하지 않습니다.

## Interaction model

- 현재 결과는 시간에 따라 변하는 물리 모델이 아니라, 선택된 카드와 검수된 표시 제약을 비교하는 결정적 학습 모델입니다.
- `pause`와 `step`은 시간 변화가 없으므로 N/A입니다.
- 실제 세탁기·다리미·표백제 조작을 흉내 내면 학생이 실제 행동 지시로 오해할 수 있으므로 안전 경계에도 맞지 않습니다.
- 향후 변수 조작을 검토할 때도 교육 목표, 관찰 가능한 변화, 설명 문장, 재시도 행동을 먼저 문서화하고 별도 승인합니다.

## Asset decision

- factual SVG 8개는 출처·검수일·의미 판정에 연결되어 있으므로 `verified-asset-preserve`로 유지합니다.
- 분위기용 이미지나 외부 사진은 현재 목표를 더 명확하게 하지 않으므로 생성하지 않습니다.
