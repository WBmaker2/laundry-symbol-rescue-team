# 세탁표시 구조대

세탁표시 구조대는 초등 교실에서 가상 옷의 취급 표시를 읽고, 세탁·건조·다림질 순서를 근거와 함께 정해 보는 정적 학습 앱입니다. 실제 의류를 판정하거나 안전을 보증하는 서비스가 아닙니다.

## 대상과 학습 목표

- 대상: 초등학교 6학년, 개인 기기 또는 교실 화면에서 25~35분
- 교육과정 연결: 실과 `[6실02-07]`의 생활 자원 관리와 `[6실02-09]`의 안전한 생활 실천을 가상 의류 관리 활동으로 연결합니다.
- 자원 절약·수선 관리: 물·에너지는 낮음·보통·높음의 상대 지표로 비교하고, 오래 입기·손상 예방·수선이 필요한 부분을 근거와 함께 살펴봅니다. 실제 비용이나 절감량은 계산하지 않습니다.

## 25~35분 학습 흐름

1. 가상 미션과 재료 모형 확인 (3~5분)
2. 취급 표시를 확대하고 뜻 후보를 확인 (5~7분)
3. 세탁·건조·다림질 관리 계획 만들기 (7~9분)
4. 손상 가능성과 표시 근거 연결하기 (4~5분)
5. 가상 결과와 상대 자원 지표 살펴보기 (3~4분)
6. 필요한 계획을 수정하고 구조 보고서 완성하기 (5~7분)

## 가상 모델과 실제 제품의 경계

화면의 옷·재료·변화는 학습용 재료 모형입니다. 결과는 실제 손상 여부나 확률을 말하지 않고 가능성과 근거를 비교합니다. 실제 옷에서는 제품 라벨과 제조사 안내, 보호자·교사의 안내를 먼저 확인하세요. 표시는 국가·시기·제품에 따라 다를 수 있으며, 모르는 표시는 보호자·교사 또는 제품 공식 안내에 확인하세요.

실제 다리미, 뜨거운 물, 표백제, 세탁기는 학생 혼자 조작하지 않아요. 앱에는 실제 기기 설정, 화학물질의 양·혼합법, 학생 단독 조작 순서를 넣지 않습니다. 전문 관리가 필요하면 보호자·교사 또는 제품 공식 안내에 확인하기를 선택합니다.

## 출처 검수

공개 취급 표시는 국내 공식 안내와 최신 KS·ISO 자료를 대조한 뒤 출처명, 공식 URL, 표준 식별자, 적용 범위, 검수일을 콘텐츠 기록에 연결합니다. 표준 모양을 그대로 쓰지 않은 표현은 학습용 아이콘으로 구분하며, 근거가 확인되지 않은 표시를 공개하지 않습니다. 자세한 검수 기록은 [`docs/content-review/2026-08-26-symbol-source-audit.md`](docs/content-review/2026-08-26-symbol-source-audit.md)에서 확인합니다.

## 개인정보와 금지 기능

진행 상태는 현재 탭의 React 메모리에만 보관합니다. 학생 이름·학급·사진·브랜드·자유 서술 개인정보를 입력받거나 저장하지 않으며, 파일 입력, 로그인, 서버 계정, 카메라/OCR, 외부 AI, 분석 도구, 원격 요청, 구매 링크, 광고, 제품 추천을 제공하지 않습니다. 실제 제품별 사용법과 얼룩 제거 화학 지침도 제공하지 않습니다.

## 개발과 검사

```bash
npm ci
npm run dev
npm test -- src/test/safety-boundaries.test.tsx
npm run test:e2e -- e2e/safety-boundaries.spec.ts
npm run test:e2e -- e2e/learner-flow.spec.ts
npm run build
npm run check
npm run test:e2e
```

`npm run check`는 린트, 타입 검사, 전체 단위 테스트, 빌드, 정적 자산 검사를 실행합니다. 외부 네트워크 요청 0건, 금지 API 부재, 안전 문구 노출, 실제 학습 흐름은 Task 14 안전 경계 테스트에서 회귀 검증합니다.

## Pages 릴리스 게이트

`.github/workflows/deploy-pages.yml`은 `main` push 또는 `workflow_dispatch`에서 Node 22, `npm ci`, Chromium 설치, `npm run check`, 전체 E2E를 통과한 뒤 GitHub Pages artifact를 배포합니다. Vite의 `base: './'`와 `public/symbols/`의 8개 로컬 SVG를 사용하므로 저장소 하위 경로에서도 정적 자산을 찾을 수 있습니다. `public/app-icon.svg`도 외부 리소스 없이 함께 빌드됩니다.

기술적 저장소·Pages 배포는 2026-08-27 `f1844ef` 커밋과 [Actions run 33041179080](https://github.com/WBmaker2/laundry-symbol-rescue-team/actions/runs/33041179080)에서 완료했습니다. 공개 주소는 [https://wbmaker2.github.io/laundry-symbol-rescue-team/](https://wbmaker2.github.io/laundry-symbol-rescue-team/)이며, 공개 HTML 제목·앱 아이콘·8개 심볼 자산과 저장소 하위 경로를 포함한 전체 브라우저 E2E 19/19를 확인했습니다.

이 기술적 배포 결과는 실제 학생·교사 화면 검토나 성인 25~35분 완주 기록을 뜻하지 않습니다. 5개 미션별 완료 화면 증거, 대표 미션의 검토자·환경·시작/종료 시각, VoiceOver 수동 읽기 순서와 Chrome 200% 수동 화면 검증은 아직 BLOCKER입니다. 자동 E2E 실행 시간은 이 인간 검토 증거를 대체하지 않으며, 필요한 수동 증거와 별도 교육용 접근성 승인 전에는 교육용 릴리스 승인으로 표시하지 않습니다.
